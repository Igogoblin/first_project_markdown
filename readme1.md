# Конспект

## Списки

- Неупорядоченные списки создаются с помощью символов -, \* или + в начале строки. Все они отображаются как маркеры (чаще всего точки).

- Упорядоченные списки создаются с помощью чисел с точкой (например, 1., 2.) в начале строки. Фактическое число часто игнорируется, и список нумеруется по порядку автоматически.

- Вложенность создается добавлением отступа (обычно 2 или 4 пробела) перед маркером элемента списка.

* проверка на другой элемент списка

## Программный код

делается тремя "```" обратными кавычками

- Строчные фрагменты обрамляются одинарными бэктиками (`).
- Блоки кода обрамляются тройными бэктиками (```) или создаются через отступ (4 пробела или 1 табуляция).
- Подсветка синтаксиса активируется указанием имени языка программирования сразу после открывающих тройных бэктиков (напр., ````python`).
  Пример кода на Python с подсветкой:

```python
def factorial(n):
    """Вычисляет факториал числа n."""
    if n == 0:
        return 1
    else:
        return n * factorial(n - 1)

result = factorial(5)
print(f"Факториал 5 равен {result}")
```
